## WeChat

Scan a code with WeChat to join the Voltip group or to follow the Official Account 六月水蓝.

<QrCode src="/community/wechat-group.png" alt="QR code of the Voltip WeChat group" caption="Voltip group" /> <QrCode src="/community/wechat-official-account.jpg" alt="QR code of the WeChat Official Account 六月水蓝" caption="Official Account 六月水蓝" />

The group's code is valid for seven days and is replaced every week. If WeChat reports that it has expired, follow the Official Account or join the Telegram group.

## Problems and suggestions

Use **Feedback** at the bottom of the sidebar, or [open an issue on GitHub](https://github.com/sunerpy/voltip/issues). The feedback dialog lists everything it sends before you send it.
