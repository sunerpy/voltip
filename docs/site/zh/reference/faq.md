# 常见问题

## 听写

### 松开快捷键后没有文字出现

先查看悬浮窗和历史记录中最新的一条，它们会说明发生了什么。

- **文字在剪贴板中**：Voltip 无法粘贴，记录中写明了原因。用 <kbd>Ctrl</kbd> <kbd>V</kbd>（Mac 上为 <kbd>⌘</kbd> <kbd>V</kbd>）粘贴即可。在 Mac 上，请确认 Voltip 已获得辅助功能权限；在 Linux 的 Wayland 会话中，请安装粘贴工具，见[各平台说明](/zh/reference/platforms#粘贴)。
- **「没有听到声音」**：录音是静音，或短于约 0.3 秒。在首页点「测试麦克风」查看强度条，并在「设置 → 麦克风」中检查输入设备。
- **出现错误**：无法连接识别服务，或缺少密钥、模型。首页会显示当前使用的服务及其所需的设置。

### 按快捷键没有反应

可能有其他应用占用了同一组合键，「设置 → 快捷键」会显示它是否注册成功。纯 Wayland 会话不允许应用注册全局快捷键，请为 `voltip-desktop --toggle` 绑定系统快捷键。

### 没有网络时能用吗？

可以，使用[本地模型](/zh/recognition/local)即可。下载一次后，识别可以离线进行。AI 润色需要服务，除非你在本机运行 Ollama。

### Voltip 会一直监听吗？

不会。麦克风在你按下快捷键时打开，录音结束后关闭。首页的麦克风测试最长运行 15 秒。

### 识别结果是繁体字

部分模型会输出繁体字。在「语音模型 → 识别设置 → 中文字形」中选择「简体」，这也是默认设置。

### 按 Esc 不能取消

Esc 只在听写录音或处理期间有效。在纯 Wayland 会话中，请改用绑定到 `voltip-desktop --cancel` 的快捷键。

## 本地模型

### 第一次在显卡上听写很慢

第一次在显卡上运行时，驱动需要为模型做一次准备。在我们实测的显卡上，这需要 13 秒到 2 分钟不等，之后的运行会很快。

### 模型下载很慢

某个下载来源速度过慢时，Voltip 会自动换到其他来源，中断的下载也会继续。你也可以用命令行下载：`voltip-desktop --download-model qwen3-asr-0.6b`。

### 较旧的电脑上无法加载 Qwen3-ASR

Qwen3-ASR 需要支持 AVX2 的处理器。请改用 SenseVoice Small、Paraformer 或云端服务。

## 安装与更新

### Windows 提示「Windows 已保护你的电脑」

安装包尚未进行代码签名。选择「更多信息」，再选择「仍要运行」。

### macOS 拦下了 Voltip，或再次要求授权

未经公证的应用在首次启动时需要确认一次，见[安装](/zh/guide/install#macos)。从 0.0.6 及更早版本更新时，钥匙串和各项权限还会再询问一次，之后的更新会保留授权。

### 我的文件在哪里？如何卸载？

见[更新、卸载与数据位置](/zh/guide/updates)。

## 手机

### 什么时候可以使用手机应用？

Android 应用已经完成并通过测试，但尚未发布。发布后会出现在[发布页面](https://github.com/sunerpy/voltip/releases)。

## 其他问题

使用侧栏底部的「反馈」，或[在 GitHub 上提交 issue](https://github.com/sunerpy/voltip/issues)。反馈对话框会在发送前列出它要发送的全部内容。
