# 常见问题

听写的表现与预期不符时，在下面找到对应的现象；每条回答都说明原因和需要调整的设置。

## 听写

### 松开快捷键后没有文字出现

先查看悬浮窗和历史记录中最新的一条，它们会说明发生了什么。

- **文字在剪贴板中**：Voltip 无法粘贴，记录中写明了原因。用 <kbd>Ctrl</kbd> <kbd>V</kbd>（Mac 上为 <kbd>⌘</kbd> <kbd>V</kbd>）粘贴即可。在 Mac 上，请确认 Voltip 已获得辅助功能权限；在 Linux 的 Wayland 会话中，请安装粘贴工具，见[各平台说明](/zh/reference/platforms#粘贴)。
- **「没有听到声音」**：录音是静音，或短于约 0.3 秒。在首页点「测试麦克风」，看「开始听写」按钮的外圈是否随声音变化，并检查输入设备：点首页上的麦克风名称，或打开「设置 → 录音来源」。
- **出现错误**：无法连接识别服务，或缺少密钥、模型。首页会显示当前使用的服务及其所需的设置。

### 边说边识别时悬浮窗没有显示文字 {#no-live-text}

使用能边说边识别的服务商时，悬浮窗显示的是这家服务返回的文字，标签写明来源，例如「预览 · 豆包语音」。没有显示时，先确认「语音模型」页所选的模型标有「边说边识别」，并且「识别设置」的「实时预览」中已打开「服务商的实时文字」；关闭后，实时识别模型仍边说边识别，只是悬浮窗不显示文字。标签为「预览 · 本地模型」时，文字来自这台电脑上的实时识别模型，而不是服务商。

然后查看历史记录中这条记录的详情。写有「实时识别中断，已改为整段识别」时，说话过程中与服务的连接中断，或服务没有返回文字；Voltip 已改为识别整段录音，文字不会丢失。后面的原因写明服务返回了几次结果、发送了多长的音频以及其中的最大音量：

- 注明「几乎没有声音」「均为静音」或最大音量很低时，请检查麦克风和录音来源：在首页点「测试麦克风」。
- 音量正常而服务没有返回文字时，请在服务商的控制台确认已开通所选的模型，并检查凭据与模型是否对应，见[服务商设置](/zh/recognition/providers)。火山引擎豆包语音还会给出日志 ID，联系火山引擎的技术支持时请提供它。

### 按快捷键没有反应

可能有其他应用占用了同一组合键，「设置 → 快捷键」会显示它是否注册成功。纯 Wayland 会话不允许应用注册全局快捷键，请为 `voltip-desktop --toggle` 绑定系统快捷键。

### 没有网络时能用吗？

可以，使用[本地模型](/zh/recognition/local)即可。下载一次后，识别可以离线进行。AI 润色需要服务，除非你在本机运行 Ollama。

### 提示内置语音识别今日额度已用完

内置服务按设备每天限量：语音识别 60 分钟、AI 润色 100 次，北京时间每天 00:00 重新计算。用完之后可以改用[本地模型](/zh/recognition/local)或其他服务商，电脑上未能识别的录音换用其他模型后可以重新识别。用量和重置时间见侧栏的「今日用量」卡片，详见[内置服务的用量](/zh/recognition/cloud#内置服务的用量)。

### 需要通过代理才能连接网络

在「设置 → 网络」中选择代理方式：默认跟随系统的代理设置，也可以手动填写代理服务器、用户名和密码，以及不使用代理的地址。识别、润色、模型下载、更新和与手机的连接都按这个设置连接，见[网络代理](/zh/recognition/cloud#网络代理)。

### Voltip 会一直监听吗？

不会。麦克风在你按下快捷键时打开，录音结束后关闭。首页的麦克风测试最长运行 15 秒。

### 识别结果是繁体字

部分模型会输出繁体字。在「语音模型 → 识别设置 → 中文字形」中选择「简体」，这也是默认设置。

### 按 Esc 不能取消

Esc 只在听写录音或处理期间有效。在纯 Wayland 会话中，请改用绑定到 `voltip-desktop --cancel` 的快捷键。

## 本地模型

### 第一次在显卡上听写很慢

第一次在显卡上运行时，驱动需要为模型做一次准备。我们的实测中，NVIDIA L40S 上约需 13 秒，Tesla T4 上约需 2 分钟，之后的运行会很快。

### 模型下载很慢

某个下载来源速度过慢时，Voltip 会自动换到其他来源，中断的下载也会继续。你也可以用命令行下载：`voltip-desktop --download-model qwen3-asr-0.6b`。

### 较旧的电脑上无法加载 Qwen3-ASR

Qwen3-ASR 需要支持 AVX2 的处理器。请改用 SenseVoice Small、Paraformer 或云端服务。

## 安装与更新

### Windows 提示「Windows 已保护你的电脑」

安装包尚未进行代码签名。选择「更多信息」，再选择「仍要运行」。

### macOS 拦下了 Voltip，或再次要求授权

未经公证的应用在首次启动时需要确认一次，见[安装](/zh/guide/install#macos)。从 0.0.6 及更早版本更新时，各项权限还会再询问一次。各版本使用同一张签名证书，更新后麦克风和辅助功能的授权会保留。一个版本读取另一个版本创建的钥匙串条目时，钥匙串会询问；0.0.15 和 0.0.16 的安装后交接实际无效，因为 updater 已先删除旧 bundle。0.0.16 安装首个带修复的版本时可能最后询问一次；两个都带修复的版本之间做应用内更新不再弹窗，手动安装仍会为每个条目询问一次。

### Voltip 提示需要系统钥匙串

Voltip 把密钥和设备身份保存在系统钥匙串中，无法打开钥匙串时不会启动，也不会改为保存到文件中。在 Linux 上，钥匙串由 Secret Service 提供：请启动并解锁 GNOME Keyring 或 KWallet。Voltip 启动时如果钥匙串要求输入密码，请输入；关闭密码提示时，Voltip 同样会显示这条说明并退出。在 Mac 上，请解锁钥匙串，并在系统询问时允许 Voltip 访问。在 Windows 上，请确认凭据管理器服务正在运行。然后重新打开 Voltip。

### Linux 上 Voltip 启动后随即退出

如果终端中显示 `Error 71 (Protocol error) dispatching to Wayland display`，并且电脑装有 NVIDIA 显卡，原因是 WebKitGTK 的 DMA-BUF 渲染。从 0.3.0 起，Voltip 在 Wayland 会话中会自动关闭它，除非你已自行设置 `WEBKIT_DISABLE_DMABUF_RENDERER`。更早的版本需要用 `WEBKIT_DISABLE_DMABUF_RENDERER=1 voltip-desktop` 启动。如果 Voltip 仍然退出，请用 `GDK_BACKEND=x11 voltip-desktop` 启动，见[各平台说明](/zh/reference/platforms#wayland-与-nvidia-显卡)。

### 我的文件在哪里？如何卸载？

见[更新、卸载与数据位置](/zh/guide/updates)。

## 手机

### 如何安装手机应用？

在手机上从[发布页面](https://github.com/sunerpy/voltip/releases)下载 `Voltip_<版本>_android_arm64.apk` 并打开，见[安装](/zh/guide/install#android)。

### 悬浮球过一会儿就消失了

部分手机会关闭在后台运行的应用。在系统设置中允许 Voltip 自启动或在后台运行，并在电池设置中关闭对 Voltip 的省电限制，见[悬浮球](/zh/phone/#悬浮球)。
