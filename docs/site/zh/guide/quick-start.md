# 快速开始

按照下面的步骤，从刚安装好的 Voltip 开始完成第一次听写，再改为在本机识别、让音频不离开电脑。

## 第一次听写

1. **启动 Voltip。** 应用打开首页，使用默认服务即可听写。
2. **授予所需的权限。** 缺少的权限会显示在首页，并附有打开相应设置的按钮：麦克风权限；在 macOS 上还需要辅助功能权限，用于粘贴文字。
3. **把光标放进任意输入框**，按住 <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>Space</kbd> 说话，然后松开。

文字会出现在光标处，结果也会显示在首页的「最近的结果」中。

如果没有文字出现，在首页点「测试麦克风」并说几句话，强度条应当有变化。要改用另一个麦克风，点首页或标题栏上的麦克风名称，再选择设备。常见原因见[常见问题](/zh/reference/faq)。

「设置 → 通用」中的设置向导会逐步引导你设置快捷键、识别服务，并试听写一次。

## 改为在本机识别

如果希望音频不离开这台电脑：

1. 在侧栏打开「语音模型」，选择「本机」。
2. 下载一个模型。推荐 **Qwen3-ASR 0.6B**（690 MB）；体积最小的是 **SenseVoice Small**（240 MB）。
3. 下载完成后选用这个模型。

此后音频不再离开这台电脑。要在已下载的模型之间切换，或改回内置服务，点标题栏或首页上的语音模型名称。[本地识别](/zh/recognition/local)对比了各个模型，并说明何时使用显卡。

## Linux 与 Wayland

纯 Wayland 会话不允许应用注册全局快捷键。请在桌面环境的键盘设置中，为命令 `voltip-desktop --toggle` 绑定一个快捷键；语音编辑使用 `voltip-desktop --edit-toggle`。「设置 → 快捷键」会显示适用于你的安装方式的完整命令，包括 AppImage 的路径。
