# Voltip 是什么

Voltip 是 Windows、macOS 和 Linux 上的语音输入工具。按住快捷键说话，松开后，文字会出现在当前应用的光标处。

## 一次听写的过程

1. **按住快捷键**，默认为 Ctrl+Alt+Space。Voltip 打开麦克风，屏幕底部出现一个小悬浮窗，显示输入音量。
2. **说话。** 安装实时识别模型后，识别出的文字会随着说话显示在悬浮窗里。
3. **松开按键。** 录音交给本机下载好的模型或云端服务识别，随后依次经过你的词典、AI 润色（已开启时）和替换规则。
4. **文字粘贴到光标处**，插入你正在使用的应用，同时在本机的历史记录中保存一份。

听写过程中任何时候按 Esc 都可以取消。

## 可以调整的地方

- **录音的开始与结束方式**：按住说话、按一次开始再按一次结束，或短按锁定长段录音；也可以用单个按键或鼠标键开始听写。见[快捷键与录音方式](/zh/dictation/shortcuts)。
- **在哪里识别**：用本地模型在这台电脑上识别，或使用内置服务、你选择的云端服务商。见[本地识别](/zh/recognition/local)和[云端服务](/zh/recognition/cloud)。
- **文字如何整理**：AI 润色、个人词典、替换规则，以及针对特定应用的场景。见[AI 润色与预设](/zh/recognition/polish)、[词典与替换规则](/zh/recognition/dictionary)和[场景](/zh/recognition/scenes)。
- **文字如何插入**：粘贴到光标处或仅复制到剪贴板；整段插入或边说边输入。见[文字的插入方式](/zh/dictation/output)。

## Voltip 不做的事

Voltip 只把语音转成文字，不做其他处理：没有唤醒词，也不会执行你说的内容。语音编辑只在你主动要求时改写选中的文字。麦克风只在录音时打开，或在首页测试麦克风时打开。

键盘和输入法照常使用，因为 Voltip 像普通应用一样通过粘贴插入文字。少数场合不接受粘贴的文字，原因见[文字的插入方式](/zh/dictation/output#无法粘贴时)。
