# 快捷键与录音方式

听写通过全局快捷键开始，在任意应用中都可以使用，默认为 <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>Space</kbd>。如需更改，打开「设置 → 快捷键」，录制新的组合键。

能注册哪些组合键取决于操作系统。「设置 → 快捷键」会显示所选组合键是否注册成功；被其他应用占用时也会说明原因。

## 录音方式

「设置 → 快捷键」提供三种录音方式：

| 方式 | 效果 |
| --- | --- |
| **按住说话**（默认） | 说话时按住快捷键，松开即结束录音并开始识别。 |
| **按一下开始，再按一下结束** | 按一次开始，再按一次结束；松开按键不会停止录音。 |
| **按住或按一下** | 与按住说话相同；短按则锁定录音，无需一直按住，再按一次结束。 |

使用第三种方式时，「短按判定阈值」决定多短的按键算作短按，默认为 300 毫秒。任何方式下，「松开后继续录音」都可以在停止后让麦克风继续开启最多 5 秒，避免最后一个字被截断。新安装默认为 150 毫秒，设为 0 则立即停止。在 Linux 电脑上用本地模型 Paraformer 实测（20 句中文和中英混说，每种情况各 3 遍）：在最后一个字说完前 0.1 秒就停止时，约 5% 的句子丢掉最后一个字，提前 0.2 秒时约 15%；设为 150 毫秒后都没有丢失。之前安装的 Voltip 保留原来的设置，可以在这里改为 150 毫秒。

按住说话时，如果松开按键的信号没有送到 Voltip（例如松开的那一刻按键被其他程序截获），Voltip 会在 1 秒内发现按键已经松开，照常结束录音。这适用于 Windows、Mac 和 Linux 的 X11 会话。

## 单个按键或鼠标键

除了组合键，还可以用单个按键开始听写：右 Ctrl、右 Alt、右 Shift、右侧的 Windows / Command / Super 键、Mac 上的 Fn 键，或鼠标的中键、后退键、前进键。它与组合键使用同一种录音方式。

- 按住它时再按其他键或点击鼠标，会取消这次按下所开始的录音，因此右 Ctrl + C 等快捷键照常可用。
- 在许多欧洲键盘布局中，右 Alt 是 AltGr，右 Shift 用于输入大写字母；选择这些键时，设置页会给出提示。
- 在 Mac 上使用 Fn 键之前，请在「系统设置 → 键盘」中把「按下 🌐 键时」设为「不执行任何操作」。
- 在 Mac 上，单键触发需要辅助功能权限；Voltip 粘贴文字时本来就需要这项权限。
- 纯 Wayland 会话不支持单键触发。

Windows 有时会停止 Voltip 对单个按键的监听，例如电脑一时非常繁忙时。Voltip 发现后会自动恢复，无需重启；电脑从睡眠中唤醒或解锁后，也会重新开始监听。「设置 → 快捷键」会显示最近一次自动恢复的时间。在 Mac 上撤销了辅助功能权限时，设置页会说明原因，重新允许后自动恢复；Linux 上与 X 服务器的连接断开时，Voltip 会自动重新连接。

## 悬浮窗

听写时，屏幕底部的悬浮窗显示当前状态：

- **录音中**：输入音量、已录时长、录制的内容（麦克风、电脑声音或混合），以及[说话时识别出的文字](#说话时显示的文字)。录音被锁定时显示锁形图标。长录音超过 2 分钟后，还会显示已识别的段数。
- **处理中**：当前步骤（识别、AI 润色或插入）及其已用时间。长录音识别时显示已完成的段数。
- **完成**：插入的字数，或文字留在剪贴板中的原因。文字没有写进去、切换了窗口或识别失败时，悬浮窗保留一张[结果卡片](/zh/dictation/output#结果卡片)，可以粘贴或复制文字。

悬浮窗显示在其他窗口之上，包括设为置顶的窗口和全屏程序。每次出现、每次状态变化时，它都会回到最上层；在 Windows 和 Mac 上，显示期间有其他窗口切换到前台或被设为置顶时，它也会保持在最上层。悬浮窗不会获取键盘焦点，因此文字仍然输入到你正在使用的应用中。

以下情况下悬浮窗仍可能被遮住：

- **Windows**：以独占全屏方式运行的游戏，以及开始菜单、通知中心等系统界面。
- **Mac**：其他应用处于全屏状态时，悬浮窗不会出现在该应用的全屏空间中。
- **Linux**：窗口的前后顺序由窗口管理器决定。位于前台的全屏窗口显示在悬浮窗之上；部分桌面环境（例如 GNOME）在悬浮窗显示期间不会把它移回最上层；纯 Wayland 会话中，前后顺序完全由桌面环境决定。

### 说话时显示的文字

录音时悬浮窗显示的文字来自服务商的实时识别，或这台电脑上的本地模型，标签写明来源，例如「预览 · 豆包语音」「预览 · 内置服务」「预览 · 本地模型」。这些文字只是预览，最终文本按所选的[输出方式](/zh/dictation/output#输出方式)生成。

「语音模型」页「识别设置」中的「实时预览」有两个开关，默认都打开：

- **服务商的实时文字**：显示内置服务的预览和实时识别模型的文字。关闭后悬浮窗不显示这些文字：实时识别模型仍边说边识别，结果和速度不变；内置服务不再发送预览请求。

## 取消

录音或处理期间按 <kbd>Esc</kbd> 即可取消，可以取消时悬浮窗会用红色显示这个键。取消后不会插入文字，也不会写入历史记录；只有「边说边输入」方式下已经输入的句子会保留。粘贴已经开始后再按 Esc，这次听写照常完成，文字照常插入并写入历史记录。Voltip 只在听写期间监听 Esc，其他时候不影响别的应用。

纯 Wayland 会话中，请为 `voltip-desktop --cancel` 绑定一个系统快捷键来取消。

## 复制上一条结果

「设置 → 快捷键」中的「复制上一条结果」可以设置单独的快捷键，默认未设置。按下后，Voltip 把最近一次结果放到剪贴板，不打开主窗口，悬浮窗显示「已复制上一条结果」。它必须与听写和语音编辑的快捷键不同。Windows 和 macOS 的托盘菜单中也有这一项，见[再次复制或粘贴结果](/zh/dictation/output#再次复制或粘贴结果)。

## 录音来源

在「设置 → 录音来源」中，或在页面标题下方的麦克风菜单中（首页以外的页面），选择听写录制的内容：

| 来源 | 录制的内容 |
| --- | --- |
| **麦克风**（默认） | 选择的麦克风，未选择时为系统默认输入。点首页「识别与润色」卡片中或页面标题下方的麦克风名称，或在「设置 → 录音来源」中选择麦克风。 |
| **电脑声音** | 电脑正在播放的声音，例如会议、通话或视频；来自选择的输出设备，未选择时为系统默认输出。 |
| **混合** | 两者同时录制。 |

混合录制时，Voltip 会从麦克风的录音中去掉扬声器播放的声音，避免电脑声音被录入两次。这一功能对应「设置 → 录音来源」中的「消除扬声器回声」，默认开启。外放音量很大时，仍建议佩戴耳机。语音编辑始终录制麦克风。

录制电脑声音在 Mac 上需要 macOS 14.6 或更高版本，在 Linux 上需要 PulseAudio 或 PipeWire 音频服务，见[平台说明](/zh/reference/platforms)。不支持时，这两个选项会置灰并显示原因。

同一页的「「可以说话」提示音」默认关闭。开启后，麦克风开始录音时播放一声约 0.1 秒的短音，表示可以开始说话。提示音不会进入识别：Voltip 把它响着的这一小段录音静音，这期间说的话也会被静音，因此请在听到提示音之后再开口。提示音只在录音来源为「麦克风」时播放，录制电脑声音时它会被录进去。使用蓝牙耳机时，系统可能因为播放提示音而切换到通话模式。

## 录音时长

录音达到「设置 → 听写」中的「最长录音时长」时自动停止，可选 1、2、5、10（默认）、30 分钟，1 小时或 2 小时。

超过 2 分钟的录音会在录制过程中分段识别：Voltip 在停顿处切分，每段约 20 至 30 秒，悬浮窗显示已识别的段数；停止后只需识别最后几段，全文很快就能完成。未能识别的部分会在文中标出时间，例如 `[未识别 00:12:30–00:13:00]`。

- 全文不超过 2000 字时才进行 AI 润色。更长的文字按识别结果插入，可以在[历史记录](/zh/dictation/history#长录音)中用 AI 预设分段处理。
- 超过 5000 字的文字不会粘贴，而是留在剪贴板中。
- 长录音进行时，音频会写入 Voltip 数据目录中的文件，录音结束后删除。

## Linux 与 Wayland

纯 Wayland 会话不允许应用注册全局快捷键或监听单个按键。请在桌面环境的键盘设置中，为下面的命令绑定快捷键：

| 命令 | 作用 |
| --- | --- |
| `voltip-desktop --toggle` | 开始听写，或结束听写并插入文字 |
| `voltip-desktop --edit-toggle` | 开始或结束一次[语音编辑](/zh/dictation/voice-edit) |
| `voltip-desktop --cancel` | 取消当前的听写 |
| `voltip-desktop --copy-last` | 把最近一次结果放到剪贴板 |

以 AppImage 运行时，把 `voltip-desktop` 换成 AppImage 的路径；「设置 → 快捷键」会显示完整命令。在通过 XWayland 运行 X11 应用的会话中，组合键只在 X11 窗口获得焦点时有效，因此同样建议使用系统快捷键。
