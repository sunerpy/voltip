# 文字的插入方式

听写结束后，Voltip 把文字插入开始录音时获得焦点的应用。插入方式由两项设置决定。

## 粘贴或复制

「设置 → 听写」中的「插入方式」有两个选项：

- **粘贴到光标处**（默认）：Voltip 把文字放到剪贴板，替你按下粘贴键（<kbd>Ctrl</kbd> <kbd>V</kbd>，Mac 上为 <kbd>⌘</kbd> <kbd>V</kbd>），然后恢复剪贴板原来的内容。
- **仅复制到剪贴板**：文字留在剪贴板中，由你自己粘贴。

## 粘贴后的剪贴板

粘贴时 Voltip 会临时借用剪贴板。你之前复制的文字、图片、文件或带格式的内容，会在粘贴完成后放回；「边说边输入」逐句粘贴时，也只在最后放回一次。如果这期间你又复制了别的内容，Voltip 保留你新复制的内容。

「设置 → 听写」中的「插入后剪贴板」决定粘贴后剪贴板中的内容：

- **恢复原内容**（默认）：放回你原来复制的内容。
- **保留识别结果**：识别结果留在剪贴板中，可以再次粘贴。

Voltip 粘贴时临时放到剪贴板上的文字不会进入 Windows 的剪贴板历史（<kbd>Win</kbd> <kbd>V</kbd>）和云剪贴板。在 Mac 和 Linux 上，Voltip 为它加上剪贴板管理器使用的临时内容标记，支持这一标记的管理器（例如 KDE 的 Klipper）不会记录它。

少数内容无法完整放回：Windows 上图元文件等以句柄形式提供的格式；Linux 上 Voltip 只能读取文件、图片、带格式的文字和纯文字，同时有几种时只放回其中一种；一次超过 64 MiB 的内容。

## 处理期间切换了窗口

Voltip 把文字插入开始听写时所在的窗口。如果在识别或润色期间切换到了其他窗口，Voltip 默认不粘贴，只把文字复制到剪贴板，避免文字出现在错误的位置。悬浮窗显示「窗口已切换，文字已复制」，你可以在需要的位置按 <kbd>Ctrl</kbd> <kbd>V</kbd>（Mac 上为 <kbd>⌘</kbd> <kbd>V</kbd>）粘贴。使用「边说边输入」时，切换窗口后的句子不再逐句输入，结束时一起复制到剪贴板。

如需粘贴到当前在前台的窗口，把「设置 → 听写」中的「处理期间切换了窗口」改为「粘贴到当前窗口」。语音编辑不受这项设置影响，切换窗口后总是只复制改写结果。开始听写时无法判断前台窗口的会话（例如 Linux 的纯 Wayland 会话）照常粘贴。插入方式为「仅复制到剪贴板」时，文字本来就只复制，切换窗口不影响结果，也不会显示这条提示。

## 输出方式

「语音模型」页的「识别设置」中有三种输出方式：

| 方式 | 效果 |
| --- | --- |
| **整段输出**（默认） | 松开快捷键后，一次性完成整段录音的识别、润色和插入。 |
| **边说边识别** | 说话过程中逐句确定，松开后只需处理最后一句；AI 润色仍在最后对全文进行一次。 |
| **边说边输入** | 每句确定后立即输入当前应用。此方式不进行 AI 润色，取消后已输入的文字不会撤回。 |

后两种方式需要边说边出字：使用内置服务或[实时识别模型](/zh/recognition/cloud#阿里云百炼)时可以直接使用；使用其他服务商或本地模型时，需要先下载实时识别模型（169 MB），下载之前按「整段输出」运行，「识别设置」中会注明这一点。使用实时识别模型时，「整段输出」按「边说边识别」运行，因为说话时就已识别。

同一页的「静音裁剪」用于本地识别：识别前裁掉语音前后的静音。它所需的小模型随第一个本地模型一起下载。

## 无法粘贴时

Voltip 无法粘贴时，文字会留在剪贴板中，不会丢失。悬浮窗和历史记录会说明原因，你可以用 <kbd>Ctrl</kbd> <kbd>V</kbd>（Mac 上为 <kbd>⌘</kbd> <kbd>V</kbd>）手动粘贴。常见原因：

| 原因 | 处理方法 |
| --- | --- |
| Mac 上 Voltip 尚未获得辅助功能权限 | 在「系统设置 → 隐私与安全性 → 辅助功能」中授予。首页有打开这项设置的按钮 |
| 目标窗口以管理员身份运行（Windows） | Windows 不允许普通应用向这类窗口输入。请以普通方式运行目标应用，或手动粘贴 |
| 焦点在密码框或 Windows 安全桌面上 | 这些位置按设计拒绝其他应用输入 |
| Linux 的 Wayland 会话中没有粘贴工具 | 为你的桌面环境安装一个工具，见[各平台说明](/zh/reference/platforms#linux) |
| 无法连接显示服务（Linux） | Voltip 是在图形会话之外启动的 |
| 长录音的全文超过 5000 字 | 这么长的文字不会直接粘贴，请在需要的位置手动粘贴。见[录音时长](/zh/dictation/shortcuts#录音时长) |
| 识别或润色期间切换到了其他窗口 | 在需要的位置手动粘贴。见[处理期间切换了窗口](#处理期间切换了窗口) |

历史记录条目中的「技术细节」保留了原始的错误信息。

## 再次复制或粘贴结果

首页「最近的结果」（指针移到一行上或用键盘移到这一行时出现）和「历史记录」页的每一行都有两个按钮：

- **复制这条结果**：把文字放到剪贴板。
- **粘贴到上一个窗口**：隐藏 Voltip，等之前使用的窗口回到前台后，把文字粘贴进去。如果回到前台的是另一个窗口，则只复制文字。

对于语音编辑，两个按钮使用的都是改写后的文字。
