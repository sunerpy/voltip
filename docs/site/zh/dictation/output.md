# 文字的插入方式

听写结束后，Voltip 把文字插入开始录音时获得焦点的应用。插入方式由两项设置决定。

## 粘贴或复制

「设置 → 听写」中的「插入方式」有两个选项：

- **粘贴到光标处**（默认）：Voltip 把文字放到剪贴板，替你按下粘贴键（<kbd>Ctrl</kbd> <kbd>V</kbd>，Mac 上为 <kbd>⌘</kbd> <kbd>V</kbd>），然后恢复剪贴板原来的内容。
- **仅复制到剪贴板**：文字留在剪贴板中，由你自己粘贴。

## 输出方式

「语音模型」页的「识别设置」中有三种输出方式：

| 方式 | 效果 |
| --- | --- |
| **整段输出**（默认） | 松开快捷键后，一次性完成整段录音的识别、润色和插入。 |
| **边说边识别** | 说话过程中逐句确定，松开后只需处理最后一句；AI 润色仍在最后对全文进行一次。 |
| **边说边输入** | 每句确定后立即输入当前应用。此方式不进行 AI 润色，取消后已输入的文字不会撤回。 |

后两种方式需要边说边出字：使用内置服务时可以直接使用；使用其他服务商或本地模型时，需要先下载实时识别模型（169 MB），下载之前按「整段输出」运行，「识别设置」中会注明这一点。

同一页的「静音裁剪」用于本地识别：识别前裁掉语音前后的静音。它所需的小模型随第一个本地模型一起下载。

## 无法粘贴时

Voltip 无法粘贴时，文字会留在剪贴板中，不会丢失。悬浮窗和历史记录会说明原因，你可以用 <kbd>Ctrl</kbd> <kbd>V</kbd>（Mac 上为 <kbd>⌘</kbd> <kbd>V</kbd>）手动粘贴。常见原因：

| 原因 | 处理方法 |
| --- | --- |
| Mac 上 Voltip 尚未获得辅助功能权限 | 在「系统设置 → 隐私与安全性 → 辅助功能」中授予。首页有打开这项设置的按钮 |
| 目标窗口以管理员身份运行（Windows） | Windows 不允许普通应用向这类窗口输入。请以普通方式运行目标应用，或手动粘贴 |
| 焦点在密码框或 Windows 安全桌面上 | 这些位置按设计拒绝其他应用输入 |
| Linux 的 Wayland 会话中没有粘贴工具 | 为你的桌面环境安装一个工具，见[各平台说明](/zh/reference/platforms#linux) |
| 无法连接显示服务（Linux） | Voltip 是在图形会话之外启动的 |
| 长录音的全文超过 5000 字 | 这么长的文字不会直接粘贴，请在需要的位置手动粘贴。见[录音时长](/zh/dictation/shortcuts#录音时长) |

历史记录条目中的「技术细节」保留了原始的错误信息。

## 再次复制或粘贴结果

首页「最近的结果」和「历史记录」页的每一行都有两个按钮：

- **复制这条结果**：把文字放到剪贴板。
- **粘贴到上一个窗口**：隐藏 Voltip，等之前使用的窗口回到前台后，把文字粘贴进去。如果回到前台的是另一个窗口，则只复制文字。

对于语音编辑，两个按钮使用的都是改写后的文字。
