# 历史记录

每次听写、语音编辑和配对手机发来的文字，都会列在「历史记录」页中。历史记录只保存在这台电脑上。

## 每条记录的内容

- 插入的文字和识别出的原文，以及两者之间的改动对比。
- 本次生效的词典纠正和替换规则，以及听写时所在的应用和[场景](/zh/recognition/scenes)。
- 进行了 AI 润色时，所用的 [AI 预设](/zh/recognition/polish#预设)。
- 使用的模型和每个步骤的耗时。
- 文字的去向：已粘贴到光标处，或留在剪贴板中及其原因。

对每条记录，你可以：

- 复制，或粘贴到之前使用的窗口（见[文字的插入方式](/zh/dictation/output#再次复制或粘贴结果)）；
- 加星标，方便查找；
- 用「加入词典」把听错的词添加到[词典](/zh/recognition/dictionary)；
- 删除。

搜索框可以查找文字、应用、场景和模型。筛选可以只显示今天、本周或本月的记录，已加星标的记录，或文字未插入的记录。

## 保留数量

在「设置 → 隐私与历史」中：

- 「保留最近」设置保留的条数：50、100、200 或 500。500 条是默认值，也是目前的上限，更早的记录会被删除。
- 可以关闭历史记录。关闭后不再记录新的听写，已有的记录保留，直到你清空为止。
- 「清空历史」在确认后删除全部记录。

## 统计

<StatusTag status="building" />

正在开发：历史记录上限提高到 2 万条，首页显示今天、本周、本月和累计的统计：

- 转录字数和修正字数；
- 说话时长和节省的时间。节省时间按说话时长 × 1.9 计算，依据 Ruan 等人 2016 年的研究（arXiv:1608.07323）：在实验中，无论英文还是中文，说话输入都比在手机上打字快约 2.9 倍。

只有听写计入统计，语音编辑和手机发来的文字不计入。
