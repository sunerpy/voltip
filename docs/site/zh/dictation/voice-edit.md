# 语音编辑

语音编辑用于改写你选中的文字。在任意应用中选中一段文字，按住 <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>E</kbd>，说出修改要求，然后松开，选中的内容会被改写结果替换。

修改要求可以是任何你会向编辑提出的要求，例如：

- 「改得正式一点。」
- 「翻译成英文。」
- 「缩短一半。」
- 「整理成列表。」

说话时悬浮窗显示「编辑」，历史记录会保存修改要求、原来选中的文字和改写结果。

## 所需条件

- **AI 服务。** 语音编辑使用与 [AI 润色](/zh/recognition/polish)相同的服务，可以是内置服务，也可以是你自己的服务商。即使关闭了「AI 润色」开关，语音编辑也照常可用。
- **不超过 2000 字的选中文字。** 没有选中文字时，这次语音编辑会停止，不发送任何内容。

如需更改或关闭这个快捷键，打开「设置 → 快捷键」。在 Linux 的 Wayland 会话中，请为 `voltip-desktop --edit-toggle` 绑定一个系统快捷键。

## 如何读取选中的文字

Voltip 用复制快捷键复制选中的文字，读取后再把剪贴板恢复原样：

- Windows 和 Linux 上使用 <kbd>Ctrl</kbd> <kbd>Insert</kbd>，因为 <kbd>Ctrl</kbd> <kbd>C</kbd> 在终端中会中断正在运行的程序。
- Mac 上使用 <kbd>⌘</kbd> <kbd>C</kbd>。

改写结果会粘贴到选中的文字上。整个过程中焦点一直在原来的应用里，选区保持高亮。

## 不适用的场合

- **Windows 和 Linux 上的终端。** 终端里的文字无法被替换，因此终端获得焦点时，语音编辑不会开始。Voltip 无法识别 VS Code 等编辑器内嵌的终端面板，请不要在那里使用语音编辑。
- **不响应复制快捷键的控件**，例如部分自绘的输入框：Voltip 读不到选中的文字，所有内容保持不变。
- **没有选中文字时会复制整行的编辑器**，例如 VS Code：改写结果会粘贴在光标处，而不是替换选区。
- 在 Windows 的部分欧洲键盘布局中，<kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>E</kbd> 等同于 AltGr+E，用于输入 €。在这类布局下请换一个快捷键。

在 X11 上使用「按住说话」时，只有松开按键后才能读取选区，因此没有选中文字的提示会在你说完之后出现。改用「按一下开始，再按一下结束」可以立即得到提示。

## 隐私

选中的文字和你的修改要求会发送给 AI 服务，与 AI 润色的目的地相同，并且只在你带着选区开始语音编辑时发送。本机的历史记录会保存修改要求、选中的文字和改写结果，可以在历史记录中删除。
