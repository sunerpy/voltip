# 场景

场景根据你说话时所在的应用调整这一次听写。开始录音时，Voltip 检查当前获得焦点的应用，并应用第一个与之匹配的场景，只对这一次听写生效。没有匹配的场景时，使用全局设置。

场景在「设置 → 场景」中设置。

## 场景包含的内容

- **应用**：场景适用的应用，可以从历史记录中出现过的应用里选择，也可以输入名称。还可以设置**窗口标题关键词**，只在标题包含其中某个关键词的窗口中生效。
- **覆盖设置**，每一项也可以选择跟随全局设置：
  - AI 润色的开启或关闭，以及润色[风格](/zh/recognition/polish#风格)；
  - [输出方式](/zh/dictation/output#输出方式)；
  - 语言；
  - 中文字形。
- **补充要求**：给 AI 服务的附加说明，最多 500 字，例如「这是聊天消息：用口语化的表达，句末不加句号。」

场景按列表顺序匹配，请把更具体的场景移到通用场景之上。例如，把标题关键词为「GitHub」的 Chrome 场景放在普通的 Chrome 场景之前。

悬浮窗会显示当前生效的场景名称，每条历史记录也会记下应用和场景。

## 如何识别应用

| 平台 | 使用的应用名称 |
| --- | --- |
| Windows | 程序文件名，不含 `.exe`，例如 `slack` |
| macOS | 应用的 Bundle ID，例如 `com.tinyspeck.slackmacgap` |
| Linux（X11） | 窗口类名，例如 `code` |

在 Mac 上不读取窗口标题，因此标题关键词不起作用。纯 Wayland 会话不会告诉应用哪个窗口获得了焦点，因此场景在那里不生效。

## 数量上限

最多 50 个场景；每个场景最多 20 个应用、10 个标题关键词。

## 内置场景

正在开发：可以直接开启、调整和恢复默认的现成场景，每个场景包含一个 [AI 预设](/zh/recognition/polish#预设)、补充要求、一组专业术语和一份应用列表。

| 场景 | 适用于 |
| --- | --- |
| 编程开发 | VS Code、Cursor、JetBrains 系列等编辑器和终端。保留代码、命令、路径和标识符的原样 |
| 办公写作 | Outlook、Word、WPS 等应用中的邮件和文档 |
| 即时聊天 | 微信、QQ、Slack、Teams、钉钉、飞书、Telegram、Discord 等聊天应用 |
| 法律、医疗、金融、学术 | 严格校对，专业术语、数字、单位和日期保持准确。添加你使用的应用后生效 |

内置场景在你开启之前不生效，你自己创建的场景优先于内置场景。
