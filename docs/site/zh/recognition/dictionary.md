# 词典与替换规则

侧栏中的两张表会在插入之前修改识别出的文字。两者都在本机运行；任何一张表出错时，听写都会按原来的文字继续完成。

## 词典

「词典」页列出识别器容易听错的词。每个词条包含：

- **正确写法**，例如 `kubectl` 或同事的名字；
- 最多 10 个**曾听成**的写法，例如「酷伯 control」。

识别完成后，文字中所有曾听成的写法会立即替换为正确写法，这一步早于 AI 润色和替换规则。已启用词条的正确写法还会作为提示发送给云端识别和 AI 润色，让它们保持这些写法。本地模型不接收提示，对它们只进行识别后的纠正。

匹配规则如下：

- 字母不区分大小写。
- 在用空格分词的语言中，只匹配完整的词：`cat` 不会替换 `concatenate` 中的部分。
- 中文、日文和韩文在任意位置都会匹配。
- 同一位置取最长的匹配，已替换的文字不会再次匹配。

页面上的「试一试」可以查看词典对一段示例文字的修改；「用最近一次听写」会填入你最近一次的识别结果。也可以在历史记录中直接纠正听错的词，见[在历史记录中纠正](#在历史记录中纠正)。

词典最多容纳 500 个词条。发送给云端服务的提示需要截短时，按词条顺序决定优先级。

## 替换规则

「规则」页在 AI 润色之后，按列表顺序改写最终文字。每条规则包含：

- 名称；
- **字面**匹配或**正则表达式**；
- 替换内容，留空表示删除匹配的文字；
- 是否区分大小写。

正则表达式使用 Rust 语法：可以用 `$1` 引用分组，但不支持环视和反向引用。无法编译的规则在保存时就会被拒绝。

规则可以从 TOML 文件导入，也可以导出为 TOML，例如：

```toml
version = 1

[[rule]]
name = "git push"
kind = "literal"
pattern = "给他 push"
replacement = "git push"

[[rule]]
name = "PR 编号"
kind = "regex"
pattern = '\bpr (\d+)'
replacement = "PR #$1"
case_sensitive = false
```

导入时可以替换整张表，也可以按名称合并到现有规则中。规则表最多容纳 200 条规则。「试运行」让一段示例文字依次经过词典和全部已启用的规则，不会插入任何内容。

## 在历史记录中纠正

在「历史记录」中打开一条记录，切换到「原文」视图，就能看到识别器写出的原文，听错的词就在这里：

- AI 润色已经改正的词带蓝色点状下划线，鼠标悬停时显示润色后的写法，例如「润色后为「Voltip」」。点按它，打开预填好的词典卡片。词典和替换规则做的改动不算在内；如果这条记录用到的词条或规则后来删除或修改过，就无法分辨哪些是润色改的，这条记录不显示这种标记。
- 已经是某个词条曾听成写法的词带绿色实线下划线。
- 选中其他听错的词，选区上方会出现工具条：「加入词典」（D）或「新建规则」（R）。双击按词选中。选区超过 64 个字符或跨行时，「加入词典」不可用，并说明原因。

卡片在选区下方打开，不会离开当前页面：

- 「曾听成」是选中的文字，「正确写法」尽量用 AI 润色后的写法预填，并注明「来自润色结果」，按 Enter 即可保存。
- 卡片会说明这次修改的影响范围，例如「除本条外，最近 499 条记录中有 3 条含「维他命」」，点「查看」显示其中几条。如果有些记录的最终文本仍保留这个写法，卡片会提醒它可能是正确用法；写法只有 1 个字时也会提醒。
- 正确写法已经是词条时，卡片把曾听成写法合并到这个词条，按钮显示「添加到「Voltip」」。写法已属于其他词条时，卡片说明原因，不能保存。
- 卡片顶部可以切换到「替换规则」：查找和替换为并排显示，并预览这条规则对本条最终文本的效果。

在「对比」视图中，点按 AI 润色做的一组改动时，卡片先询问哪一种写法正确：选择润色后的写法，就把原文中的写法加入词典；选择原文的写法（AI 润色改错了），就把它作为正确写法加入词典，之后 AI 润色会保留这个写法。

保存后，窗口底部显示「已加入词典 · Voltip」，5 秒内点「撤销」或按 Ctrl Z 可以撤回。已经保存的历史记录不会改变，词典和规则只作用于之后的听写。

手机上，在记录详情中点「纠正识别错误」，原文按词显示，点按一个词选中它，再点按另一个词可以扩大选择范围，然后在底部选择「加入词典」或「新建规则」。

如果希望由 Claude Code、Codex 等 AI 工具结合项目经验分析历史记录并提出词条，见 [AI 工具接入](/zh/recognition/mcp)。

## 简体与繁体

在「语音模型」页「识别设置」的「中文字形」中，可以选择**简体**（默认）、**繁体**或**保持原样**。字形在识别之后立即转换，因此词典按你选择的字形进行匹配。
