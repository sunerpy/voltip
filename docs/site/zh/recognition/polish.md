# AI 润色与预设

AI 润色在插入之前整理识别出的文字：修正标点和错别字，删除口头禅和重复。它不改变你说的内容，不翻译，也不添加内容。

用标题栏的「AI 润色」开关开启或关闭。[场景](/zh/recognition/scenes)可以针对特定应用开启或关闭润色。

## 服务

AI 润色使用「AI 模型」页中选择的服务：内置服务、OpenAI、Groq、硅基流动、DeepSeek、本机的 Ollama，或任意 OpenAI 兼容接口。设置方法见[云端服务](/zh/recognition/cloud)。

如果服务没有响应，Voltip 会插入未经润色的识别结果，这次听写不会丢失。

## 风格

场景可以为它覆盖的应用选择以下三种风格之一：

| 风格 | 效果 |
| --- | --- |
| **标准** | 修正标点、错别字和口头禅，如上所述 |
| **只加标点** | 只补充标点，不做其他修改 |
| **书面语** | 把口语化的说法改写为书面语 |

## AI 服务收到的内容

- 经过词典纠正后的识别文字。不会发送音频。
- 你正在输入的应用的名称，可以关闭。
- 窗口标题，仅在你开启后发送。
- 当前生效的场景中的补充要求（如有）。
- 词典中的正确写法，让服务保持这些写法不变。

两个开关位于「设置 → 场景」的「发送给 AI 润色的上下文」中。它们只在 AI 润色开启时生效；识别服务永远不会收到这些上下文。

使用「边说边输入」时，每句识别出来就立即插入，因此不进行 AI 润色。

## 预设

<StatusTag status="building" />

正在开发：多个内置预设，可以在首页、「AI 润色」开关旁的菜单或托盘中切换。

| 预设 | 作用 |
| --- | --- |
| **校对**（默认） | 修正错字、同音字和标点，分段，删除口头禅和结巴。遇到「不对，应该是……」这类改口时，只保留改正后的说法 |
| **提示词优化** | 把口述的需求改写成给另一个 AI 的清晰提示词：需求简单时写成一句准确的指令，要点较多时整理成编号列表 |
| **意图整理** | 保留改口后的说法，去掉重复，把多个要点整理成列表 |
| **口语聊天** | 口语化的短句，句末不加句号 |
| **中英互译** | 先修正识别错误，再在中文和英文之间互译 |
| **要点纪要** | 整理成「要点」和「待办」两组列表，不添加事实 |
| **只加标点**、**书面语** | 即上面的两种风格，作为预设提供 |

你还可以编写自己的预设，保存前先用示例文本试用，并为每个场景选择预设。
