# AI 工具接入

AI 工具接入让这台电脑上的 AI 工具（例如 Claude Code、Codex）通过 MCP 读取 Voltip 的历史记录、词典和规则，找出反复出现的识别错误，并添加词条和规则。这些工具了解你的项目和用语，判断哪个写法正确比通用的规则更可靠。读取哪些内容、能否修改，都由你在设置中决定，每次修改都可以撤销。

只有桌面版提供这项功能。

## 开启

打开「设置 → AI 工具接入」：

- 「启用 MCP 服务」开启服务。「状态」显示「运行中」和服务地址，例如 `http://127.0.0.1:47841/mcp`，以及最近连接的工具。
- 「端口」用于更改端口（1024–65535），服务会在新端口上重新启动。端口已被占用时，状态显示「无法启动」和原因。
- 服务只接受来自这台电脑的连接，每个请求都须携带访问令牌。关闭开关或退出 Voltip 时，服务随之停止。

## 连接 Claude Code 或 Codex

在「接入」中点「复制命令」，再在终端中运行。复制的命令已经填入访问令牌，窗口中不显示令牌内容。

- **Claude Code**：

  ```bash
  claude mcp add --transport http voltip http://127.0.0.1:47841/mcp \
    --header "Authorization: Bearer <令牌>"
  ```

- **Codex**：先设置环境变量，再添加服务：

  ```bash
  export VOLTIP_MCP_TOKEN=<令牌>
  codex mcp add voltip --url http://127.0.0.1:47841/mcp --bearer-token-env-var VOLTIP_MCP_TOKEN
  ```

  在 Windows 上，复制的命令用 PowerShell 的写法设置环境变量：`$env:VOLTIP_MCP_TOKEN = "<令牌>"`。

其他支持 Streamable HTTP 的 MCP 客户端，填写同样的地址，并在请求头中加上 `Authorization: Bearer <令牌>`。

连接后可以直接向工具提出要求，例如「检查最近一个月 Voltip 听错了哪些词，结合这个项目的术语给出词典建议，经我确认后再添加」。工具还可以使用 Voltip 提供的提示 `review_misrecognitions`：先汇总替换，再逐条回测，把建议列给你确认后再写入。

## 读取范围

| 选项 | AI 工具可以读取 |
|---|---|
| 仅词典和规则 | 词典、规则和它们的命中次数；可以试运行一段文字，回测只返回条数 |
| 替换汇总（推荐，默认） | 以上全部，以及 AI 润色前后被替换的词语、出现次数，和命中处前后各 12 个字的片段，不包含整条记录 |
| 完整历史 | 以上全部，以及所选时间范围内每条记录的原文、润色后的文本、应用与场景名称 |

选择「完整历史」时，Voltip 会先说明风险，并请你选择时间范围（最近 7 天、最近 30 天或全部记录，默认最近 30 天）。授权后，设置页一直显示「已允许读取完整历史记录（最近 30 天）。」这样的提示，点「收回」或改选其他选项后立即生效。

AI 工具读取的内容会发送给它所使用的模型服务，并可能保存在它的对话记录中。历史记录可能包含个人信息、账号或其他敏感内容，只在需要时授权「完整历史」。

工具请求超出授权的内容时，会收到一条说明，例如「当前只允许读取替换汇总；完整记录需要在 Voltip 设置中授权」，它可以把这句话转告给你。

## 修改权限

| 选项 | AI 工具可以 |
|---|---|
| 只读 | 不能修改词典和规则 |
| 修改词典，新建规则需确认（推荐，默认） | 添加和修改词条（包括停用）；新建规则，但新规则在你确认之前不会生效 |
| 也可以直接启用规则 | 以上全部，并可以新建立即生效的规则、修改任何规则 |

替换规则会改写之后插入到任何应用中的文字，所以默认需要你确认：外部工具新建的规则在「规则」页标为「待确认」，点「启用」后才会生效，也可以直接删除。选择「也可以直接启用规则」时，Voltip 会再次确认。

AI 工具不能删除词条和规则。

## 查看和撤销修改

- AI 工具写入时，窗口底部会显示提示，例如「Claude Code 添加了 2 个词条」，点「查看」打开词典；写入了规则时打开规则页。
- 「设置 → AI 工具接入 → 最近活动」列出每次读取和修改：哪个工具、什么时间、读取了什么或改了什么，不记录文字内容。修改可以在这里撤销。
- 「词典」页的来源会写明「外部工具 · Claude Code」，筛选「外部工具」只显示这些词条。「规则」页顶部会提示待确认的规则，筛选「待确认」只显示这些规则。待确认的规则不参与试运行。

## 工具

| 工具 | 作用 | 需要的授权 |
|---|---|---|
| `dictionary_list` | 列出词条、曾听成写法、是否启用、来源和命中次数 | 任意读取范围 |
| `rules_list` | 列出规则、类型、是否启用、是否待确认、来源和命中次数 | 任意读取范围 |
| `vocabulary_preview` | 让一段文字经过词典和规则，可以附带一条规则草稿 | 任意读取范围 |
| `vocabulary_backtest` | 回测一个词条或规则草稿：最近的记录中有多少条会被改动，以及其中可能属于正常用法的条数 | 任意读取范围；示例片段需要「替换汇总」 |
| `vocabulary_candidates` | 汇总 AI 润色前后被替换的词语和出现次数 | 替换汇总 |
| `history_search` | 按文字、时间或应用查找记录，每页最多 50 条 | 完整历史 |
| `history_get` | 读取一条记录的全部文字 | 完整历史 |
| `dictionary_add` | 添加词条；正确写法已存在时，把曾听成写法合并进去 | 修改词典 |
| `dictionary_update` | 修改词条的写法、曾听成写法或是否启用 | 修改词典 |
| `rules_add` | 新建规则；默认在你确认后才生效 | 修改词典 |
| `rules_update` | 修改规则；默认只能修改它自己新建、仍待确认的规则 | 修改词典 |

## 隐私与安全

- 服务默认关闭，只监听 `127.0.0.1`，不接受其他电脑的连接；来自网页的请求一律拒绝，网页无法读取服务的响应。
- 访问令牌与[本机服务](/zh/recognition/service)的令牌不同，因此只用于语音识别的程序读不到历史记录。「重新生成」在确认后更换令牌，旧令牌立即失效。
- 每次请求最多返回 50 条记录、256 KiB。Voltip 的日志只记录工具名称、客户端名称、条数和耗时，不记录文字内容。
- 如果需要从另一台电脑使用，请通过 SSH 端口转发连接到这台电脑，例如 `ssh -L 47841:127.0.0.1:47841 <这台电脑>`。
