# 云端服务

识别和 AI 润色都可以使用互联网上的服务，而不使用本地模型。两者分别设置：识别在「语音模型」页，AI 润色在「AI 模型」页。

## 内置服务

正式版安装包内置了一项服务，无需任何设置即可听写和使用 AI 润色。它由 Voltip 项目运营，不需要密钥。从源码构建的版本没有内置服务。

## 服务商

| 服务商 | 识别 | AI 润色 | 密钥 |
| --- | --- | --- | --- |
| 内置服务 | 支持 | 支持 | 不需要 |
| 本机 | 支持，使用[本地模型](/zh/recognition/local) | — | 不需要 |
| OpenAI | 支持 | 支持 | 必填 |
| Groq | 支持 | 支持 | 必填 |
| 硅基流动 | 支持 | 支持 | 必填 |
| DeepSeek | — | 支持 | 必填 |
| Ollama（本机运行） | — | 支持 | 不需要 |
| 自定义，任意 OpenAI 兼容接口 | 支持 | 支持 | 可选；接口地址必填 |

同时提供两项服务的服务商，两项服务共用一把密钥。

## 设置服务商

1. 在「语音模型」或「AI 模型」页展开该服务商的卡片。
2. 选择模型；自定义接口还需要填写接口地址。
3. 填写你的密钥。「测试连接」会检查地址和密钥，并列出该服务商提供的模型。
4. 选择「使用」切换到这个服务商。

## 切换模型

标题栏和首页显示当前使用的语音模型和 AI 润色模型，以及它们是否就绪。点击模型名称即可切换，无需打开对应页面：

- 语音模型菜单列出内置服务、已设置的服务商，以及已下载的本地模型。
- AI 润色模型菜单位于「AI 润色」开关右侧，列出内置服务和已设置的服务商提供的模型。

尚未设置的服务商不会出现在菜单中。菜单末尾的「管理语音模型…」和「管理 AI 模型…」会打开设置它们的页面。

## 密钥

- 密钥保存在系统钥匙串中：Windows 凭据管理器、macOS 钥匙串或 Linux 的 Secret Service。保存后界面不再显示。
- 每把密钥只发送给它所属的服务商。切换服务商或修改自定义地址时，原来的密钥不会随之发送。
- 在 Linux 上，Voltip 需要正在运行的 Secret Service，例如 GNOME 钥匙串或 KWallet。它不会改为把密钥保存到文件中。

## 发送的内容

- **识别**：录音、模型名称和你的密钥。如果[词典](/zh/recognition/dictionary)中有词条，它们的正确写法会作为识别提示一并发送。
- **AI 润色**：识别出的文字，不包括音频；默认附带当前应用的名称，可以关闭。详见[隐私](/zh/privacy)。
