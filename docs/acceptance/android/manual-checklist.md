# Android 真机手测清单

CI 会构建、签名并检查 APK 与 AAB，还会在模拟器上启动应用（PR 上是 `ci.yml` 的 `android-device` 作业，发布候选封存前是 `release-candidate.yml` 的 `device-android` 作业：x86_64 的 Android 15 模拟器经 ARM 翻译运行 arm64 代码，确认首屏出现、20 秒内不退出、日志里没有致命错误）。模拟器没有真实的麦克风、相机、剪贴板交互和定制系统，下面这些要在一部真机上人工确认，每项记下「通过 / 不通过 + 现象」，并写明机型与系统版本。

0.0.18 与 0.0.19 在小米 HyperOS 3 上打开即闪退（2026-10-01 用户反馈；原因见 `docs/runbook.md`「Android 构建（本机）」）：当时只做了包检查，从没有启动过发布的 APK。所以每次改动了手机端的版本，发布后都要至少走一遍第 1–5 项。

## 准备

1. 在手机上从 GitHub Release 下载 `Voltip_<版本>_android_arm64.apk` 并打开。系统询问是否允许浏览器或文件管理器安装应用时，为这次安装选择允许。
2. 手机上装过用其他密钥签名的版本（本机构建的 debug 包）时，先卸载再安装；各个正式版本之间可以直接覆盖安装。
3. 需要网络：未配对时的识别与润色用内置服务。

## 清单

| # | 操作 | 期望 |
|---|---|---|
| 1 | 点图标启动 Voltip，停留 30 秒 | 首屏出现「用手机说话」卡片，按钮写「按住说话」和「在手机上识别」；应用不退出 |
| 2 | 第一次按住「按住说话」 | 弹出麦克风权限请求；允许后开始录音，按钮变为「松开识别」，下方计时并有电平条 |
| 3 | 未配对时说一句话后松开 | 依次显示「正在识别…」「正在润色…」，最后显示「已复制到剪贴板：文字」；到其他应用里粘贴，得到同样的文字；「最近结果」里出现这一条 |
| 4 | 在「最近结果」里点「复制」，再点「分享」 | 复制后提示「已复制」，粘贴得到这条文字；分享弹出系统分享面板，选一个应用能收到这条文字 |
| 5 | 按住说话，手指滑出按钮再松开 | 按钮变为「松开取消」，松开后显示「已取消」，「最近结果」没有新增 |
| 6 | 在系统设置里撤销麦克风权限，再按住说话 | 提示麦克风权限被拒绝，按钮恢复为「按住说话」 |
| 7 | 点「连接电脑」，在电脑的「手机」页开始配对，分别用扫码、6 位验证码、「附近的电脑」各配对一次 | 扫码时弹出相机权限请求；两边显示同一组安全码，确认后进入「已配对设备」页 |
| 8 | 电脑在线时按住说话 | 按钮写「发送到 {电脑名称}」；文字出现在电脑的光标处，手机显示「已插入电脑：文字」 |
| 9 | 在电脑上退出 Voltip，再按住说话 | 卡片里出现「已配对的电脑都不在线，现在在手机上识别。」，按钮写「在手机上识别」；结果复制到手机剪贴板 |
| 10 | 电脑在线时在「发送文字到电脑」里输入一段文字发送，再点「发送剪贴板」 | 两次的文字都插入电脑的光标处 |
| 11 | 应用切到后台 1 分钟再回来；锁屏后解锁 | 应用不退出，回来后已配对的电脑重新显示在线 |
| 12 | 覆盖安装下一个正式版本 | 安装成功，不需要卸载；配对关系、「最近结果」都还在 |
| 13 | 定制系统（HyperOS、ColorOS 等）：在省电模式下锁屏 10 分钟后打开 | 应用能打开；记录是否需要在系统设置里允许自启动或关闭省电限制才能保持连接 |
| 14 | 电脑在线时打开手机的「记录」，在顶部从「这部手机」切到电脑的名称；再在电脑上说一句话，然后在电脑上删除一条记录；最后打开「设置 › 电脑 › {电脑名称} 的设置」 | 列表与电脑「历史记录」页一致，上方写「已同步 N 条 · 刚刚」；新的一条几秒内出现在手机上，删除的那条随之消失；手机上的电脑记录只能复制、分享，不能收藏或删除；电脑设置页显示电脑的语音模型、AI 润色、预设、词典、规则和场景，只能查看 |
| 15 | 在电脑的「手机」页关掉这部手机的「同步」开关，再打开 | 关掉后手机上这台电脑写「这台电脑关闭了同步」，它的记录和设置从手机上删除；打开后重新同步，记录全部回来 |
| 16 | 在电脑上退出 Voltip，在手机上识别两句话，再启动电脑上的 Voltip | 电脑「历史记录」里出现这两条，来源写「手机 · {手机名称}」；手机上的这两条仍在；在电脑上删除其中一条，手机上的那条不受影响 |
| 17 | 进入「设置」›「外观与语言」，用屏幕边缘的返回手势（或返回键）依次返回；再在「设置」›「个人词典」打开一个词条的编辑框后返回；应用开着时在系统设置里改一次字体大小，回到应用后再按返回走一遍 | 依次回到「设置」和「说话」；在「说话」中第一次返回显示「再返回一次即可退出」，两秒内再返回一次退出应用，超过两秒则重新提示；编辑框先被关闭，页面不变 |
| 18 | 在桌面上查看 Voltip 的图标；Android 13 及以上开启主题图标后再看一次 | 图标是 Voltip 的标志（深蓝底上白色和橙色的 V），不是 Tauri 的默认图标；圆形和圆角方形的图标都完整显示 V；主题图标下是单色的 V |
| 19 | 从 GitHub 发布页安装上一个版本，打开「设置 › 关于」点「检查更新」，再点「下载新版本」；装好后再点一次「检查更新」 | 「软件更新」显示「有新版本 {新版本} · 当前 {旧版本}」和更新说明；浏览器下载 `Voltip_<新版本>_android_arm64.apk`，打开后覆盖安装，配对关系和记录都还在；之后显示「已是最新」 |
| 20 | （上架 Google Play 后）从 Google Play 安装，打开「设置 › 关于」 | 显示「由 Google Play 更新」，没有「检查更新」；「在 Google Play 中打开」进入 Voltip 在 Google Play 上的页面 |
| 21 | 电脑在线时，在手机上按住说话发送两句话到电脑；然后打开手机的「说话」和「记录」 | 「最近结果」和「记录 › 这部手机」都有这两条，标为「发送到 {电脑名称}」；点开一条进入详情；「记录」顶部的「今天」「累计」听写次数各加 2；电脑的「历史记录」里每句只有一条（来源「手机 · {手机名称}」），不会因为手机的记录再多一条 |
| 22 | 在手机上点开任意下拉框（「说话」的「场景」、「记录」的筛选、「设置」里的语言等），再看按钮、开关和分段选择 | 下拉框在页面内弹出与桌面一致的选项列表，不出现系统自带的单选对话框；按下按钮时有按压效果，没有蓝色或灰色的点击闪烁；返回手势先关闭打开的列表 |
