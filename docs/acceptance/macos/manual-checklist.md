# macOS 桌面手测清单

CI 能构建、签名（普通 CI 为 ad-hoc，发布候选为项目的固定证书）并检查 `.app` 与 `.dmg`，跑无头入口（CI `macos` job 的运行摘要）。下面这些要在一台登录了桌面的 Mac 上人工确认，每项记下「通过 / 不通过 + 现象」。Apple 芯片（M 系列）的 Mac 用 GitHub Release 里的 `Voltip_<版本>_aarch64.dmg`，Intel 芯片的 Mac 用 `Voltip_<版本>_x64.dmg`；也可以取 CI `macos` job 最近一次运行的 `voltip-macos-aarch64` / `voltip-macos-x64` 产物里的同名文件。一键安装脚本（README 的「Install」）会按芯片自动选。

## 准备

1. 打开 `.dmg`，把 `Voltip.app` 拖到「应用程序」。应用用项目自己的自签名证书签名、没有公证，第一次打开会被拦下：macOS 15 起在「系统设置 → 隐私与安全性」底部点「仍要打开」；macOS 11–14 在「应用程序」里按住 Control 点 Voltip，选「打开」。也可以执行 `xattr -dr com.apple.quarantine /Applications/Voltip.app` 后再打开。
2. 「系统设置 → 键盘 → 输入法」里先留一个英文布局（ABC 或 U.S.）。

## 清单

| # | 操作 | 期望 |
|---|---|---|
| 1 | 启动 Voltip | 主窗口直接打开首页，不进设置向导；菜单栏有托盘图标（V 字标志）；缺少的权限（麦克风、辅助功能）在首页顶部提示，带授权按钮 |
| 2 | 在首页的权限提示里（或「设置 → 通用 → 设置向导」）依次请求两项权限 | 弹出系统授权框；授权后状态变为「已允许」，不用重启 |
| 3 | 设置 → 热键：保留 `Ctrl+Alt+Space`，在「备忘录」里按住说话，松开 | 屏幕下方出现透明胶囊，显示输入强度与识别中；松开后文字粘贴进备忘录，剪贴板恢复成原来的内容 |
| 4 | 激活方式改为「切换」，按一下开始、再按一下结束 | 同上 |
| 5 | 引擎里装好「轻量」本地模型并选中，断网后再听写一次 | 不联网也能出字 |
| 6 | 打开「实时预览」，听写一段较长的话 | 胶囊里有逐步出现的预览文字 |
| 7 | 在「备忘录」里选中一段文字，按 `Ctrl+Alt+E`（需先在设置里启用编辑热键并配好润色）说「改得更正式」 | 选区被改写结果替换 |
| 8 | 在「终端」里选中文字后按编辑热键 | 提示「终端里不支持语音编辑」，终端里什么都不发生 |
| 9 | 输入法切到「Dvorak」，在「备忘录」里再听写一次 | 文字照常粘贴（不是按到 `.` 键）；切回 ABC 后也正常 |
| 10 | 关闭主窗口，再点程序坞图标 | 主窗口重新出现（Reopen）；托盘菜单能打开主窗口、退出 |
| 11 | 在「系统设置 → 隐私与安全性」里撤销麦克风权限，再听写 | 给出「麦克风未授权」的提示，而不是没有反应 |
| 12 | 终端里执行 `/Applications/Voltip.app/Contents/MacOS/voltip-desktop --list-compute`；装好「均衡」模型后执行 `… --transcribe-file <16 kHz wav> --model qwen3-asr-0.6b --json` 两次 | `--list-compute` 列出一行 `gpu`（Metal）；两次输出的 `backend` 都是 `Metal`；记下两次的 `latency_ms`（每次都是新进程，都含 Metal 初始化） |

| 13 | 双击 `.dmg` | 挂载出的窗口里有 `Voltip.app` 和「应用程序」的替身；拖入后能按「准备」第 1 步打开，不会提示「已损坏」 |
| 14 | 装着 0.0.6 或更早的版本（ad-hoc 签名）时，在「设置 → 关于」里检查更新并安装第一个固定证书的版本（0.0.7） | 下载本机芯片对应的 `Voltip_<新版本>_<aarch64 或 x64>.app.tar.gz`、校验签名后替换应用并重启，「关于」显示新版本；这一次钥匙串会为每个条目弹窗（点「始终允许」；点「允许」只放行这一次，下次启动或更新还会再问，直到点了「始终允许」），辅助功能与麦克风可能要在系统设置里关掉再打开（仍无效时 `tccutil reset Accessibility dev.voltip.desktop` / `tccutil reset Microphone dev.voltip.desktop`），记下实际需要哪几步 |
| 15 | 装着固定证书的版本（0.0.7 或更新）时，在应用里更新到下一版——**待用户确认**（0.0.10 → 0.0.11） | 更新后启动不弹钥匙串；不用重新授权，麦克风和辅助功能都还有效，听写直接插入。2026-09-30 用户从 0.0.7 更新到 0.0.10 时，`voltip.identity.*` 弹过一次：这个条目存于 ad-hoc 签名的 0.0.6，0.0.7 那次只放行了一次（「允许」），所以它仍只信任 0.0.6。点「始终允许」后不再弹。CI 的 `macos` job 用 `.github/scripts/check-keychain-across-updates.sh` 在两台 Mac 上验证同一机制 |
| 16 | macOS 14.6 或更高版本：「设置 → 录音来源」选「电脑声音」，播放一段有人说话的视频，听写约 20 秒 | 第一次录制时系统询问是否允许 Voltip 录制其他应用的声音（说明文字是 `NSAudioCaptureUsageDescription` 那句）；允许后胶囊显示「电脑声音」，识别出的是视频里的话 |
| 17 | 选「混合」，戴耳机播放视频的同时自己说几句 | 两者都被识别出来；不戴耳机外放时出现回声属预期，设置页有提示 |
| 18 | 「设置 → 听写」把最长录音时长设为 10 分钟，对着视频录 3 分钟以上再停止 | 超过 2 分钟后胶囊显示「已识别 N 段」；停止后很快插入全文；历史记录里这一条有「用 AI 预设处理」和两个导出按钮，导出的 SRT 能在播放器里加载 |
| 19 | macOS 14.6 以下的机器（如有）打开「设置 → 录音来源」 | 「电脑声音」「混合」置灰，写明需要 macOS 14.6 或更高版本 |

结果回填到 `docs/acceptance.md` 对应的 B6 行，或直接告诉维护者。
